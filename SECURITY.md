# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to `legal@talia.events`. Include the
affected URL/component, impact and minimal reproduction steps. Do not include
real customer data, OAuth tokens, mailbox contents or destructive proof.

Do not open a public GitHub or Linear issue for an unpatched vulnerability.
TALIA aims to acknowledge critical reports within four hours and other reports
within two business days. Remediation targets are documented in
`docs/security/vulnerability-management.md`.

If you believe Google Workspace data or OAuth credentials were accessed without
authorization, mark the subject `URGENT SECURITY INCIDENT`.

## Supported version

Security fixes target the current production version. Historical deployments
are not supported and may be disabled after a security release.
