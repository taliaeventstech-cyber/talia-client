# TALIA subprocessors

Last updated: 2 August 2026

This list applies when TALIA processes Customer Personal Data as a processor, operator or service provider.

| Provider | Service and processing purpose | Expected processing regions |
| --- | --- | --- |
| Supabase | Database, authentication, storage and managed PostgreSQL | European Union, according to project configuration |
| Vercel | Web application and server-side API hosting | European Union and United States, according to deployment routing |
| Fly.io | TALIA AI runtime and operational services | European Union, according to configured region |
| OpenAI | Response generation, classification and embeddings | European Union or United States, according to account and endpoint configuration |
| Stripe | Subscriptions, checkout, invoices and payment identifiers | European Union and United States |
| Google | Gmail integration when enabled by Customer | Global, including European Union and United States |
| Microsoft | Microsoft 365/Outlook integration when enabled by Customer | Global, including European Union and United States |

TALIA does not authorize subprocessors to use Customer Content to train general-purpose models. Material changes to this list should be communicated to affected customers through the contractual contact channel.

Contact: `legal@talia.events`
